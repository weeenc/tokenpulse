# Repository Instructions

## Git branch naming

- Never create a branch whose name starts with `codex/` or `codex-`.
- Name branches as `<type>/<short-kebab-case-description>`.
- Use one of these types: `feat`, `fix`, `hotfix`, `release`, `chore`, `docs`, `refactor`, `test`, `ci`, or `build`.
- Keep branch names lowercase and use only ASCII letters, digits, hyphens, and the single slash after the type.
- Choose a concise description of the change; do not use a person, tool, or agent name as the prefix.

Examples: `feat/token-budget-alerts`, `fix/login-redirect`, `docs/deployment-guide`.
